# Projeto-portifolio
Projeto Portfólio Profissional – Lucas Pereira

Este projeto consiste no desenvolvimento do meu site portfólio profissional, criado para apresentar minha atuação como desenvolvedor Frontend em transição de carreira, com foco em projetos reais aplicados à área da construção civil e pequenos negócios.

O portfólio foi desenvolvido com o objetivo de unir clareza visual, organização de código e estrutura semântica, servindo tanto como vitrine profissional quanto como base evolutiva para futuros projetos.

Objetivo do Projeto

Apresentar meus serviços e projetos de forma profissional

Consolidar boas práticas de HTML semântico e CSS organizado

Criar uma base reutilizável para projetos institucionais reais

Servir como portfólio técnico para recrutadores e clientes

Este projeto é utilizado como aplicação real, não apenas como exercício acadêmico.

Tecnologias Utilizadas

HTML5 – Estrutura semântica e acessível

CSS3 – Estilização responsiva e organizada (uso de variáveis)

JavaScript (em evolução) – Interações e melhorias progressivas

Git & GitHub – Versionamento e histórico de evolução do projeto

Funcionalidades

Layout responsivo para desktop e mobile

Seções institucionais (apresentação, serviços, projetos, contato)

Estrutura preparada para integração com WhatsApp e links externos

Código organizado para facilitar manutenção e evolução

Status do Projeto

🚧 Em desenvolvimento contínuo

O projeto recebe melhorias constantes de layout, responsividade, organização de código e futuras integrações com JavaScript.

Próximos Passos Planejados

Aprimorar interações com JavaScript

Otimizar performance e acessibilidade

Publicar versão final para uso profissional

Evoluir para integração com backend no futuro
